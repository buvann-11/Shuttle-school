# Security

Shuttle School is a static site. It has no server, no accounts and no analytics, and it never sends your data anywhere: progress and settings live in your browser's local storage.

The production build ships a strict Content Security Policy (scripts, styles, fonts and images from the site's own origin only; the one inline script is allowed by hash).

If you find a security problem, please use GitHub's **Report a vulnerability** button on the repository's Security tab rather than opening a public issue.
